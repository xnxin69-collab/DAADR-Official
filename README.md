## AI治理模型 AI Governance Model

```
人类提案 Human Proposal
    ↓
AI审议 AI Review (偏见检测 / 合规检查 / 风险评估)
    ↓
社区投票 Community Vote (Quadratic Voting)
    ↓
链上自动执行 On-Chain Auto Execution
```

- **代码即宪法 Code is Constitution**
- **AI为公仆 AI as Public Servant, not Ruler**
- **透明可审计 Transparent & Auditable**
- **反特权黑箱 Anti-Privilege Black Box**
